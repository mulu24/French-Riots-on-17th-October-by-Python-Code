# French-Riots-on-17th-October-by-Python-Code
I run monte-carlo simulation to see how much money France lost on student's strike on 17th of October.

French unrest and public debt: macro models in Python

Python models behind an essay on how the 2026 French protests and riots interact with France's debt burden. They cover a Monte Carlo estimate of the cost of the unrest, debt-to-GDP dynamics, and the OAT-Bund spread.

Read this first. Cost figures are model estimates, not official totals. Ranges for policing, firefighters, tear gas, schools, transport and lost output are the author's assumptions. The IFRAP and DBRS figures come from a secondary source (realtyinvestor.eu); the IFRAP page itself was not accessible, so check them against the original. Not financial advice.
